## Exercises

### Lottery Coupon Generator

A simple program that generates lottery columns using random numbers.

Features:

* Choose the number of columns
* Add a fixed number
* Exclude unwanted numbers
* Generate 6 unique numbers per column
* Prevent duplicate columns
* Sort numbers in each column
